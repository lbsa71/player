# Example records

These records were produced by the real `--neural` demo using the pinned Beat
This! small model and the original CC0 signals generated by `scripts/demo.py`.
`analysis.json` and `beats.json` are the steady signal's records. `mix-plan.json`
contains all three tracks; its fallback diagnostics are intentional. `models.json`
records the exact converted weights used.

References here illustrate the actual storage contract. They point into the
corresponding generated library; this directory alone is not a portable library
snapshot. To produce a self-contained library, fresh plan, transition auditions
and complete WAV with verified references:

```sh
cd Sources/Analyzer
python3 scripts/demo.py --output ./demo-neural --neural
```

The fresh library has new UUIDs; use its saved plan ID. Audio generation,
fixed start/end selection and DSP settings are reproducible. No model accuracy,
acoustic-recording quality or reference-parity claim follows from these synthetic
examples. The variable-grid and stretch-alignment fixtures are separate tests.
